# 조선 1웨이브 방 탐험

Unity 메뉴 `TakeUp > Open Wave 1 Room Map` 또는 `Scenes/JoseonWaveOne.unity`를 열고 Play.
기존 파견 튜토리얼을 마쳐도 이 씬으로 진입합니다.

- 이동 WASD/방향키, 마우스 조준 + 좌클릭 공격, Shift 대시, E 상호작용.
- 시작방에서 아래로 이동하면 마을길(8마리). 오른쪽은 포탈 수비대(12마리), 다시 오른쪽은 포탈.
- 마을길 아래는 선택 전투(10마리), 오른쪽 봉인석은 체력 35% 회복 + 증강 선택 1회.
- 방 안쪽으로 진입하면 문이 잠깁니다. 1.2초 준비 후 몬스터가 순차 등장하며, 예정된 몬스터 전부 등장 + 전멸 시 개방됩니다.
- 각 전투방 최초 완료 시 증강 선택 1회. 처치 경험치와 레벨업 증강도 유지됩니다.
- 정리한 방에는 적이 다시 나오지 않습니다. 필수 전투방 2개 완료 후 포탈 가까이서 E를 누르면 1웨이브 완료.
- 이번 프로토타입은 1웨이브까지만 구현. 2~7웨이브와 보스 자동 연결은 없습니다.

## 편집

Hierarchy의 `Wave 1 · Rooms and Gates` 아래에 바닥, 벽, 문, 포탈, 봉인석이 저장되어 있습니다.
루트의 RoomWaveMap 컴포넌트에서 방별 enemyCount, spawnInterval, warningDuration을 변경합니다.
방 위치/크기를 바꾸면 rooms의 bounds와 실제 벽·문·통로 배치를 함께 수정해야 합니다.
플레이 상태에서 변경한 내용은 저장되지 않습니다. 외형은 회색 상자 형태의 동선 테스트용입니다.

## 검증

RoomWaveSetup.CreateAndBuild: 전용 씬 생성(이미 있으면 보존), Windows 개발 빌드.
플레이어 실행 인수 `--takeup-room-smoke`: 방 봉쇄, 순차 생성 완료 전 문 개방 금지, 전멸 보상, 재진입, 봉인석 일회성, 포탈 조건, 재시작 검사.
`--takeup-room-preview`: 맵 전체 화면을 실행 파일 옆 wave-one-overview.png에 저장.
