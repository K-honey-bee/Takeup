# TakeUp — 선사시대 생존 프로토타입

## 추가 기능 — 발구르기 댄스 / 대시 / 증강 도감

- **Tab**: 전체 증강 도감 열기/닫기. 획득한 증강은 컬러와 중첩 수, 미획득은 어둡게 표시합니다. 페이지 버튼으로 모든 항목을 확인합니다. 열려 있는 동안 전투는 정지합니다.
- **Shift**: 마지막 이동 방향으로 짧게 대시합니다. 대시 중에는 접촉 피해를 받지 않으며, 재사용 대기시간이 있습니다.
- **Q**: 전설 스킬 **발구르기 댄스**. 현재는 즉시 테스트하도록 기본 해금되어 있습니다.
- 춤 중 **A/D 또는 좌/우 방향키**로 표시된 순서를 박자에 맞춰 입력하세요. 첫 박자까지 준비 시간이 있으며 하단의 움직이는 점이 중앙선에 닿을 때 누릅니다.
- 제자리에서 춤추며 이동·대시·자동 공격을 멈춥니다. 기존 투사체와 적, 생성·스테이지 시간은 느리게 흐릅니다. 춤 중에는 피격되지 않습니다.
- 정확한 입력마다 카메라가 단계적으로 줌인하고 임시 캐릭터가 좌우로 흔들립니다. 모든 입력 성공 시 원형 충격파가 퍼져 적마다 한 번씩 피해를 줍니다.
- 반대 방향, 너무 빠른/늦은 입력, 입력 누락, 좌우 동시 입력은 실패입니다. 실패 효과음과 함께 카메라가 줌아웃하고 전투로 복귀합니다. 성공·실패 모두 쿨다운을 적용합니다.
- **ESC**는 춤 중에도 사용 가능합니다. 음악과 리듬 시간이 함께 정지하고 재개됩니다. 춤 중 Tab은 열리지 않습니다.

### 음악과 이미지 교체

`TakeUp > Select Gameplay Settings` → **전설 스킬 / 발구르기 댄스 > Dance**를 펼칩니다.

| 항목 | 용도 |
| --- | --- |
| Start Unlocked | 체크 해제 시 레벨업에서 전설 증강을 획득해야 Q 사용 가능 |
| Sequence | 좌/우 순서. 기본값 좌·우·좌·우·좌·좌·우. 12개 초과 시 입력 표시가 이동 |
| Bpm | 음악과 입력의 박자 간격. 음악을 자동 분석하지 않으므로 직접 맞춥니다 |
| First Beat Time | 음악 파일의 시작부터 첫 입력까지 초 단위 시간 |
| Hit Window | 각 박자의 앞뒤 허용 시간 |
| Input Latency Offset | 오디오/입력 지연 보정. 양수는 늦은 입력을 보정 |
| Enemy Time Scale | 춤 중 주변 전투 속도. 기본 0.15배 |
| Final Zoom Ratio / Beat Zoom Kick | 최대 줌인 비율 / 성공 입력마다 순간적인 줌인 |
| Camera Return Speed | 성공·실패 후 카메라 복귀 속도 |
| Cooldown / Damage / Radius / Wave Speed | 재사용 시간 / 충격파 피해 / 최대 반경 / 전파 속도 |
| Dance Frames | 춤 이미지 목록. 성공 박자마다 다음 스프라이트로 교체 후 종료 시 원래 그림으로 복구 |
| Shockwave Sprite / Color | 충격파 그림과 색. 중앙이 빈 원형 이미지를 권장 |
| Left Arrow / Right Arrow / Panel Sprite | 리듬 방향 아이콘 / 패널 배경 |
| Music | 춤 배경 음악. 비워두면 설정 BPM에 맞춘 임시 타악 리듬 생성 |
| Beat / Hit / Success / Failure Sound | 박자 안내 / 입력 성공 / 완벽 성공 / 실패 효과음 |
| Play Metronome / Volume | 사용자 음악 위에 박자음 추가 여부 / 스킬 오디오 음량 |

이미지는 Sprite (2D and UI), 음악·효과음은 AudioClip으로 드래그해 넣습니다. 음악은 첫 박자 위치와 BPM을 맞춘 뒤 플레이로 확인하세요. 프레임별 이미지 교체는 구현했지만 최종 춤 애니메이션과 실제 음악은 제공하지 않습니다.
시너지와 **하나의 그림**은 후속 설계 대상으로 남아 있습니다. 이번 추가 범위는 도감·대시·발구르기 연출과 전투 연결입니다.

## 시작

1. Unity Hub에서 이 프로젝트 폴더 `Takeup/TakeUp`을 Unity **6000.3.9f1**로 엽니다.
2. `Assets/TakeUpPrototype/Scenes/PrehistoricPrototype.unity`를 엽니다.
   상단 메뉴 **TakeUp > Open Prototype Scene**으로도 열 수 있습니다.
3. Play를 누릅니다. 플레이어는 황금색 원, 적은 붉은 마름모로 표시됩니다.

## 조작과 진행

- WASD / 방향키 / 게임패드 왼쪽 스틱: 상하좌우 이동. 대각선 속도는 정규화됩니다.
- 범위 안에서 가장 가까운 적을 향해 돌을 자동으로 던집니다.
- 적을 처치하면 녹색 경험치가 떨어집니다. 가까이 가면 끌어당겨 수집합니다.
- 레벨업마다 전투가 정지하고 증강 3개 중 하나를 클릭하거나 숫자 1/2/3으로 선택합니다.
- 큰 경험치를 한 번에 획득해 여러 레벨이 오르면 선택을 순서대로 모두 받습니다.
- ESC: 일시정지 / 재개. 사망 또는 일시정지 화면에서 다시 시작할 수 있습니다.
- 30초마다 웨이브가 강화됩니다. 2웨이브부터 빠른 적, 3웨이브부터 큰 적이 등장합니다.
- 180초 생존하면 **보스 진입 준비** 화면이 표시됩니다. 실제 보스 전투는 아직 없습니다.

## 이미지와 게임 수치 바꾸기 — Inspector

**TakeUp > Select Gameplay Settings** 또는
`Assets/TakeUpPrototype/Data/PrehistoricSettings.asset`을 선택합니다.

이미지를 Assets 안으로 가져온 뒤 Texture Type을 **Sprite (2D and UI)**로 바꾸고 Apply합니다.
도트는 Filter Mode **Point**, Compression **None**으로 설정하면 선명합니다.

| 설정 | 바꾸는 내용 |
| --- | --- |
| Player Sprite / Tint / Size | 플레이어 그림, 색, 월드 크기 |
| Stone Sprite / Size | 돌 투사체 그림과 크기 |
| Spear Sprite / Size | 창 투사체 그림과 가로·세로 크기. 원본은 오른쪽을 향하도록 제작 |
| Experience Sprite / Tint | 경험치 아이템 그림과 색 |
| Ground Sprite / Tint | 맵 배경. 배경 전체 크기로 늘려 표시 |
| Enemies > 각 항목 > Sprite / Tint / Size | 몬스터 종류별 그림, 색, 크기 |
| Enemies > First Wave / Spawn Weight | 등장 웨이브, 상대적 등장 비율 |
| Enemies > Health / Speed / Damage / Experience | 체력, 이동 속도, 접촉 피해, 경험치 |
| Augments > 각 항목 > Icon / Title / Description | 증강 카드 그림, 이름, 설명 |
| Augments > Kind / Amount / Max Stacks | 강화 종류, 증가량, 최대 획득 횟수 |
| Stage Duration / Wave Duration | 생존 목표 시간 / 웨이브 간격 |
| Max Alive Enemies | 동시에 존재할 수 있는 몬스터 상한 |

원본 그림의 색을 그대로 쓰려면 해당 **Tint를 흰색**으로 설정하세요.
플레이어·몬스터 그림은 비율을 유지하며 Size에 맞춰집니다. 이 프로토타입은 단일 스프라이트와 좌우 반전을 사용하며 방향별 걷기 애니메이션은 아직 없습니다.
설정 변경은 Play를 종료하고 다시 시작해 확인하세요. Play 중 설정 에셋을 바꾸면 그 값이 저장될 수 있습니다.

## 구조

- `SurvivalSettings.cs`: 인스펙터에서 조절하는 데이터. 시대별 설정 에셋으로 확장 가능.
- `SurvivalGame.cs`: 이동, 자동 공격, 웨이브, 적 추적, 경험치, 증강, 게임 상태.
- `SurvivalHud.cs`: 한국어 HUD, 선택 카드, 일시정지와 결과 화면.
- `Editor/PrototypeSetup.cs`: 설정과 씬 생성, 메뉴, 개발 빌드.
- `SurvivalSmokeTest.cs`: `--takeup-smoke` 실행 인수가 있을 때만 실행되는 통합 점검.

몬스터·투사체·경험치는 Play 중 생성됩니다. 편집 모드에 보이지 않는 것이 정상입니다.
기본 SampleScene은 보존되어 있으며 프로토타입 씬을 빌드 목록 첫 번째에 추가했습니다.
적은 화면 바깥에서 생성되어 추적하며 플레이어만 맵 테두리 안으로 제한됩니다.
충돌은 원형 거리와 투사체 이동 구간을 사용합니다. 현재 지형 장애물과 길찾기는 없습니다.
최대 적 100개, 경험치 250개 이후에는 가까운 경험치에 수량을 합쳐 보존합니다.

## 현재 범위와 다음 단계

이번 범위는 **이동 → 돌 공격 → 몬스터 처치 → 경험치 → 증강 → 창 해금 → 생존 완료**입니다.
시대 전환, 저장, 상점, 최종 아트·사운드는 포함하지 않았습니다. 문어 보스는 별도 씬으로 구현되어 있습니다.

문어 보스는 생존 완료 후 보스 진입 버튼으로 연결됩니다. 상세 패턴은 아래를 참고하세요.

## 문어 보스 패턴 (2026-10-18)

`Scenes/OctopusBossPrototype.unity`에서 테스트합니다. 생존 스테이지 구성은 변경하지 않았습니다.
- 체력 50% 이상: 랜덤 4색 기억 → 촉수 휘두르기 → 양쪽 내려치기 반복. 색은 중복될 수 있습니다.
- 50% 미만: 현재 패턴을 끊고 빨간 범위 예고 → 촉수 강타만 반복합니다. 예고 시작 시 플레이어 위치를 기준으로 공격선이 고정됩니다.
- 0: 무적 상태로 랜덤 5색을 보여준 뒤, 원형 8방향 색 촉수가 맵 전체를 덮습니다. 각 차례의 준비 시간이 끝날 때 기억한 색 영역 안에 있어야 합니다. 정답은 피해 없이 성공 처리합니다. 다섯 번 성공하면 클리어, 한 번 틀리면 보스 체력 30%로 회복하고 폭주 재개입니다.
- 발악 중에는 바위를 통과할 수 있어 색 영역으로 이동할 수 있습니다. 각 색은 반대편에도 배치됩니다. 경계선에서는 플레이어 중심점의 각도로 판정합니다.

`Data/OctopusBossSettings.asset` Inspector에서 조절:
- `Rage Angles`: 공격 각도 목록(0 가로, 90 세로, 45/-45 대각선), 순서대로 반복.
- `Rage Warning Time`, `Rage Impact Time`, `Rage Interval`, `Rage Width`: 예고/공격/간격/폭.
- `Finale Flash Time`, `Finale Move Time`, `Finale Impact Time`: 색 표시/자리 이동/펼침 연출 시간.

현재 몸체와 일반/폭주 촉수는 기존 SpriteRenderer를 사용하므로 스프라이트를 교체할 수 있습니다. 발악 원형 촉수는 색상 부채꼴 Mesh로 임시 표현하며 `OctopusBossEncounter.Patterns.cs`의 `ShowRadial`이 연출 지점입니다. 판정은 `FinaleColorAt`으로 분리되어 있습니다.

## 불 증강

레벨업 3개 선택 카드와 Tab 증강 도감에 다음 5종이 추가됩니다.
- 불의 발견(1회): 돌/창 적중 시 기본 초당 6 피해, 3초 화상. 반복 적중은 남은 시간만 갱신합니다.
- 뜨거운 불씨(최대 4회): 화상 초당 기본 피해 +3. 일반 공격력 증가도 화상에 적용됩니다.
- 오래 타는 불(최대 3회): 화상 지속 시간 +1.5초.
- 불씨 확산(1회): 화상 중인 적을 처치하면 주변 3m 적에게 화상 전파. 직접 공격/충격파/화상 처치 모두 적용됩니다.
- 불의 춤(1회): 성공한 발구르기 충격파에 화상 추가. 실패 시에는 발동하지 않습니다.

강화 4종은 불의 발견 획득 후 등장하며 불의 춤은 발구르기 보유도 필요합니다. 일시정지/증강 선택/도감에서는 화상이 멈추고, 리듬 의식 중에는 적과 같은 느린 시간으로 진행합니다. 보스 진입/재도전 시 증강 보유가 유지되며, 체력 0 발악에서는 남은 화상을 제거하여 색 패턴을 건너뛰지 않습니다.

`PrehistoricSettings`와 `BossPlayerSettings`의 `Fire`에서 기본 피해/시간/확산 반경/색/불씨 이미지를 조절할 수 있습니다. 증강 배열의 Amount는 뜨거운 불씨의 초당 피해 증가량과 오래 타는 불의 초 증가량입니다. 관련 값을 바꾸면 카드 설명도 함께 수정하세요. 현재 불씨는 주황색 도형, 확산은 주황색 원으로 표현합니다.

## 선사시대 추가 증강

- 튕기는 돌(1회): 돌이 맞은 지점에서 5m 이내 가장 가까운 다른 적에게 한 번 튕깁니다. 이미 맞힌 적은 다시 맞히지 않으며 대상이 없으면 사라집니다. 창과 가시에는 적용하지 않습니다. 불의 발견을 보유하면 튕긴 돌도 화상을 부여합니다.
- 가시 가죽(1회): 피해를 받고 생존하면 8방향으로 가시를 발사합니다. 기본 피해 18, 사거리 5m이며 일반 공격력 증강이 적용됩니다. 무적/대시로 막은 피해와 0 피해에는 발동하지 않습니다. 가시 자체에는 불이나 튕김이 적용되지 않습니다.

두 증강은 선행 조건 없이 레벨업 카드와 Tab 도감에 등장합니다. 보스 진입/재도전에서도 보유가 유지됩니다. `PrehistoricSettings` / `BossPlayerSettings`의 `Primitive`에서 튕김 탐색 범위, 가시 피해·개수·속도·사거리·색·이미지를 조절할 수 있습니다. 설정 수치를 바꾸면 카드 설명도 함께 수정하세요.
